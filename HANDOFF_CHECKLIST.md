# Handoff checklist

## Ready for prototype delivery
- [x] Dashboard, Lineup, integrated Market, Rankings, Competitions, Games & Results.
- [x] World selector and EN/PT/ES.
- [x] Player/coach selection and budget validation.
- [x] Calendar navigation and stored future-game display.
- [x] Public-source synchronization adapters.
- [x] Offline syntax/integrity tests.
- [x] Temporary VS Code public preview path.
- [x] Render/Gunicorn deployment configuration.

## Required before a real public launch
- [ ] Real user authentication, password reset and account verification.
- [ ] Server-side user profiles, lineups, leagues, predictions and history.
- [ ] PostgreSQL migration.
- [ ] Automated scheduled data jobs and job dashboard.
- [ ] Final scoring/round-lock rules and audit trail.
- [ ] Production admin panel.
- [ ] Monitoring, alerting and backups.
- [ ] Privacy Policy, Terms and data-source/licensing review.
- [ ] Real payment provider only if Budget Boost becomes a paid feature.
